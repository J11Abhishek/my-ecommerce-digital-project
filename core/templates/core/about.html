About this project

ShopSphere is a practice e-commerce application built with Matrix. It implements a complete shopping workflow: registration, product browsing with search and filters, a stock-aware cart, checkout with a saved address book, a simulated payment step, order history and a full administrator dashboard.

What it demonstrates

  • Custom user model with e-mail login and a profile + address book
  • Model relationships: Category → Product → OrderItem → Order → User
  • Search, filtering, sorting and pagination with the ORM only
  • Business rules enforced in service functions (stock limits, cancellation, price snapshots)
  • Transactions with select_for_update so stock cannot be oversold
  • Class based admin plus a custom dashboard with sales reporting

Out of scope

Real payment gateways, shipping APIs, recommendations, multi-vendor support and multi-currency.
